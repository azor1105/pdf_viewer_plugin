# pdf_viewer_plugin

A new Flutter plugin project.

## iOS: Swift Package Manager

The iOS side of this plugin ships as a Swift package (`ios/pdf_viewer_plugin/`)
and has no CocoaPods podspec. Apps that depend on it must have Flutter's Swift
Package Manager support turned on:

```sh
flutter config --enable-swift-package-manager
```

See [Swift Package Manager for app developers](https://docs.flutter.dev/packages-and-plugins/swift-package-manager/for-app-developers)
for how to migrate an existing app off CocoaPods.
